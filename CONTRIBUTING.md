# How to work with the model · Ako pracovať s modelom

🇬🇧 English first, 🇸🇰 Slovensky below.

## 🇬🇧 Rules

1. **One package, one owner.** Fewer conflicts.
2. **Always `git pull` first.**
3. **Work on your own branch**: `ST0XX-package-name`.
4. **Save the model and close EA before committing** (the `.qea` file must be released).
5. **Never merge a `.qea` in the GitHub UI.** Resolve conflicts locally in LemonTree: *parent* (common ancestor), *ours*, *theirs*.
6. **Small changes, frequent commits.**

## 🇸🇰 Pravidlá

1. **Jeden balík = jeden vlastník.** Menej konfliktov.
2. **Vždy najprv `git pull`.**
3. **Pracuj na vlastnej vetve**: `ST0XX-nazov-balika`.
4. **Pred commitom ulož model a zavri EA** (súbor `.qea` musí byť uvoľnený).
5. **`.qea` sa nemerguje v GitHub UI.** Konflikt riešiš lokálne v LemonTree: *parent* (spoločný predok), *ours*, *theirs*.
6. **Malé zmeny, časté commity.**
